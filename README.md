# 🚖 Cab Booking System – SQL Data Analysis Project

## 📌 Project Overview

This project demonstrates the use of SQL to design and work with a cab booking database.

The database contains information about customers, drivers, cabs, and cab bookings. The project focuses on database creation, data management, relationships between tables, and SQL-based analysis.

## 🗄️ Database Structure

The project includes the following tables:

- **Customers** – Customer details such as name, phone, email, signup date, and city.
- **Drivers** – Driver details including phone, license number, joining date, and city.
- **Cabs** – Cab information including cab type, registration number, model, and assigned driver.
- **Bookings** – Booking details including customer, driver, cab, booking date/time, pickup and drop-off locations, booking status, and fare.

## 🛠️ Technologies Used

- SQL
- MySQL

## 🔍 Key SQL Concepts

- Database and table creation
- Primary Keys
- Foreign Keys
- Constraints
- Data insertion
- Data manipulation
- Relational database design
- SQL queries for analysis

## 🎯 Project Objective

The objective of this project is to build a structured cab booking database and use SQL to analyze booking-related data and derive meaningful insights.
